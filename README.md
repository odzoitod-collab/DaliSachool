# Далі — онлайн-школа

Лендінг школи підготовки до НМТ на Next.js, TypeScript і PostgreSQL. Форма запису зберігає заявки в таблиці `leads`.

## Запуск

1. Встановіть залежності: `npm install`.
2. Запустіть PostgreSQL: `docker compose up -d` (або використайте власну базу).
3. Скопіюйте `.env.example` у `.env.local` і за потреби змініть `DATABASE_URL`.
4. Запустіть сайт: `npm run dev` і відкрийте http://localhost:3000.

Таблиця заявок створюється автоматично під час першого успішного надсилання; користувач бази має мати право створювати таблиці. Для production налаштуйте власні облікові дані та захист доступу до бази.
